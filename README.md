# Agile Sprint Simulator

Azure DevOps inspired Agile board built with React and Vite.

## Features

- Sprint dashboard
- Agile taskboard
- Azure DevOps inspired UI
- Move tickets across columns
- Sprint selector
- Sidebar navigation
- Reusable React components

## Technologies

- React
- Vite
- JavaScript
- CSS

## Project Structure

```text
src
 ├── components
 │    ├── Sidebar.jsx
 │    ├── MetricCard.jsx
 │    └── TicketCard.jsx
 │
 ├── data
 │
 ├── App.jsx
 ├── App.css
```

## Run Project

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Open browser:

```text
http://localhost:5173
```
